## Third-party data

Map features are downloaded from [OpenStreetMap](https://www.openstreetmap.org) via the
[Overpass API](https://overpass-api.de/). OpenStreetMap data is © OpenStreetMap
contributors and is licensed separately under the
[Open Database License (ODbL)](https://www.openstreetmap.org/copyright) — the BSD license
below covers this software, not the map data it retrieves. If you redistribute `.mapdata`
files or products derived from them, the ODbL's attribution and share-alike terms apply to
that data.

The optional basemap tile layers in the viewer (Thunderforest, Seznam) are third-party
services with their own terms of use and require your own API keys.
